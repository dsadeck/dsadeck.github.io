Grindspace — Spaced Repetition for the NeetCode 150

A free, open-source web app that uses a Leitner-style spaced repetition scheduler to help you actually retain your solutions to the NeetCode 150 LeetCode problems instead of re-solving the same ones forever.

How it works:

  • Solve a LeetCode problem.
  • Rate how it went: Again, Hard, Good, or Easy.
  • Grindspace schedules the next review (1 / 3 / 7 / 16 / 35 days).
  • All progress lives in your browser — no account, no backend, no tracking.
